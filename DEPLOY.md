# Deploy ProjectIQ to the Internet

ProjectIQ can be hosted in three ways, from fastest to most permanent:

| Option | Time | Cost | Best for |
|--------|------|------|----------|
| **A. Cloudflare Tunnel** | ~5 min | Free | Quick demo, sharing with team |
| **B. Docker on your PC** | ~10 min | Free | Always-on from your machine |
| **C. Cloud hosting (Render)** | ~20 min | Free tier | Permanent URL, no PC needed |

---

## Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (for options B and C)
- Optional: [Cloudflare cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) for the best tunnel experience

---

## Option A — Quick internet access (Cloudflare Tunnel)

Best if you want a public link **right now** without paying for cloud hosting.

### Step 1: Start the app

**Production (recommended — single port):**
```bat
deploy.bat
```

**Or dev mode (two ports):**
```bat
start-external.bat
```

### Step 2: Open a public tunnel

```bat
start-tunnel.bat
```

Choose option **1** if you used `deploy.bat`, or **2** if you used `start-external.bat`.

You'll get a URL like:
```
https://random-words.trycloudflare.com
```

Share that URL — anyone on the internet can access your app.

> **Note:** The URL changes each time you restart the tunnel (unless you set up a named Cloudflare tunnel with a custom domain).

---

## Option B — Docker production on your PC

Runs ProjectIQ as a single service on port **8000** (frontend + API together).

```bat
deploy.bat
```

Open **http://localhost:8000**

### Useful commands

```bat
docker compose logs -f          :: view logs
docker compose down             :: stop
docker compose up --build -d    :: rebuild after code changes
```

### Expose to the internet

Keep Docker running, then in another terminal:

```bat
start-tunnel.bat
```

Choose option **1** (port 8000).

## Option C — Permanent cloud hosting (Render)

Host on Render so the app runs 24/7 without your PC.

### Step 1: Push code to GitHub

1. Create a repo on [GitHub](https://github.com/new)
2. Push this project:

```bash
git init
git add .
git commit -m "Initial ProjectIQ deploy"
git remote add origin https://github.com/YOUR_USERNAME/projectiq.git
git push -u origin main
```

### Step 2: Deploy on Render

1. Go to [render.com](https://render.com) and sign up
2. Click **New → Blueprint**
3. Connect your GitHub repo
4. Render reads `render.yaml` automatically
5. Set `OPENAI_API_KEY` in the environment variables (optional)
6. Click **Apply**

Render builds the Docker image and gives you a URL like:
```
https://projectiq.onrender.com
```

### Important notes for Render free tier

- The app **spins down after 15 minutes** of inactivity; first load may take ~30 seconds
- A **1 GB persistent disk** stores your SQLite database
- Change the default passwords after going live!

## Environment variables

| Variable | Required | Description |
|----------|----------|-------------|
| `SECRET_KEY` | **Yes** (production) | Random string for JWT tokens. Auto-generated by `deploy.bat`. |
| `OPENAI_API_KEY` | No | Enables live AI. Without it, mock AI responses are used. |
| `DATABASE_URL` | No | Default: SQLite. Set to PostgreSQL URL for managed DB. |
| `SERVE_FRONTEND` | No | Set `true` in Docker/production. |
| `STATIC_DIR` | No | Path to built React app. Default: `/app/static` in Docker. |

---

## Security checklist before going public

1. **Change default passwords** — log in as admin and create new users; disable or rename demo accounts
2. **Set a strong `SECRET_KEY`** — never use the dev default in production
3. **Use HTTPS** — Cloudflare Tunnel and Render provide this automatically
4. **Don't commit `.env`** — it contains secrets

---

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `deploy.bat` fails | Ensure Docker Desktop is running |
| Tunnel URL loads but login fails | Use tunnel option **1** with `deploy.bat`, not dev mode |
| Blank page after deploy | Check `docker compose logs` — frontend build may have failed |
| Data lost after redeploy | Ensure persistent volume/disk is mounted (`/app/data`) |
| AI features not working | Set `OPENAI_API_KEY` in environment variables |

## Architecture (production)

```
Internet → Cloudflare Tunnel / Render
                ↓
         FastAPI (port 8000)
         ├── /api/*     → Backend API
         └── /*         → React SPA (static files)
                ↓
         SQLite (/app/data/manufacturing_pm.db)
```
